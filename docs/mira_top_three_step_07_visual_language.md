# Step 07 — Visual language review

**Status:** Approved and locked in the UI Lab on 2026-10-21; native transfer pending.

Review page: [Visual language](http://localhost:5173/design/step-07/visual-language.html)

## Accepted decisions

- Keep the sprout companion as Talk's expressive hero, with listening, thinking, and speaking poses mapped to conversation states.
- Keep Activities and Journal illustrations quieter and smaller; let the content stay primary.
- Use the existing Material Design Icons family for navigation and actions. Illustrations carry character; interface icons remain familiar and scannable.
- Allow only low amplitude, optional Talk idle motion and purposeful state changes. Keep controls still at rest and honor reduced-motion preferences.
- Check mascot visibility and contrast on all three selected palettes. Keep the illustration itself consistent across themes.

The page is a visual proposal, not a production screen or behavior change. Existing selected palettes, forest wordmark, Nunito Sans, and current type sizes are unchanged.
