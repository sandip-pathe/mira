# Mira buildathon deck

- `Mira-Symphony-Buildathon.pdf` is the five-slide, self-contained PDF. Its artwork and fonts are embedded; the project link on the last slide is clickable.
- `index.html` is the editable Reveal.js deck. Reveal.js and presenter notes are bundled in `vendor/`; images are copied into `assets/`.
- `assets/` contains copies of every original image in `mobile/assets/brand/`. Original project files were left in place. The forest wordmark PNG is a tinted derivative used by the PDF.
