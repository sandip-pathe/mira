# Mira wordmark color comparison

The selected logo is the **Casual signature in forest green**. Blue and black remain available in the UI Lab for side-by-side reference. Open `comparison.html` to view each on the same Talk screen. The main preview's **Logo color** selector has those same three choices.

The selected forest version and its blue/black variants use CSS color filters on the same transparent PNG so their size and letterforms stay identical. These remain UI Lab explorations; the native app is unchanged.
